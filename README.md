# Login React Tainwild

Implementasi halaman login bergaya glassmorphism menggunakan React dan Tailwind CSS.

## Prasyarat

- Node.js 18+
- npm

## Memulai

```bash
npm install
npm run dev
```

Buka `http://localhost:5173` untuk melihat aplikasi.

## Build Produksi

```bash
npm run build
```

Folder `dist/` akan berisi aset produksi.
